1. Introduction

This implementation report for the CSS Multi-column Layout Module Level 1 documents the test suite results across current browser engines to support transitioning the specification to Candidate Recommendation / Recommendation.

The report reflects automated testing against the official Web Platform Tests (WPT) test suite for multi-column layout.

2. Results Summary

TO DO: The following stats need updating once tests for other specs and L2 of this spec are moved.

The test suite in css/css-multicol contains 717 test cases in total. Of these, 708 test cases cover Level 1 requirements, while 9 test cases relate to future levels of this specification (such as CSS Multi-column Layout Level 2).

  • 635 / 717 (88.6%) overall tests pass in 2 or more independent implementations.
  • 477 / 717 (66.5%) overall tests pass in all 3 tested implementations.
  • Chrome (Blink): 707 / 717 (98.6%) passing
  • Firefox (Gecko): 607 / 717 (84.7%) passing
  • Safari (WebKit): 510 / 717 (71.1%) passing

Conclusion: The CR implementation criteria (at least two independent interoperable implementations for each feature) are fulfilled across the core features of CSS Multi-column Layout Level 1.
